# متابعة الحلقات

صفحة PWA لمتابعة حلقات المسلسلات (روابط Facebook Reels) وحفظ مكانك في كل مسلسل.

المسلسلات الحالية: كابتن تسوباسا (87 حلقة)، كوروكو باسكت بول (75 حلقة)، عدنان ولينا (26 حلقة).

## إضافة مسلسل جديد

كل المسلسلات في ملف `shows.js`. انسخ بلوك مسلسل كامل وعدّل:

- `id`: اسم قصير بحروف إنجليزية بدون مسافات، وما يتغيرش بعد كده.
- `name`: اسم المسلسل اللي يظهر في الصفحة.
- `seasons`: كل موسم له `name` وقائمة `ids`، وهي أرقام الريلز من روابط فيسبوك بالترتيب.

مسلسل من موسم واحد يتكتب بموسم واحد وخلاص، والصفحة بتخفي تبويبات المواسم لوحدها.

ما تغيّرش `id` لمسلسل موجود ولا ترتيب حلقاته، علشان التقدم المحفوظ ما يتلخبطش.

## ملاحظات

- التقدم محفوظ على الجهاز نفسه (localStorage)، ومنه نسخة احتياطية كملف JSON من أسفل الصفحة.
- بعد أي تعديل الصفحة بتتحدث لوحدها أول ما تتفتح والنت شغال.
